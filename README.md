# 企業リサーチシステム

日本の上場企業の財務データを取得し、収益性・健全性・成長性・効率性を可視化する Streamlit アプリ。

![Python](https://img.shields.io/badge/Python-3.10-blue) ![Streamlit](https://img.shields.io/badge/Streamlit-1.47-red)

## できること

- **企業概要** — 業種・上場市場・従業員数・時価総額・直近期の成長率・従業員一人当たり売上
- **財務分析** — 直近5期の損益計算書／貸借対照表／キャッシュフローと、ROE・ROA・自己資本比率・負債比率などの推移
- **レポート出力** — 上記を Markdown 形式でダウンロード

## データについて

| 項目 | 内容 |
|---|---|
| 出典 | Yahoo! Finance（`yfinance` 経由で取得） |
| 同梱データ | 5社分のスナップショットを `data/financials.json` に固めてある。**APIキー不要で動く** |
| 収録外の企業 | サイドバーに証券コードを入力すると、その場で取得する |
| 単位 | 百万円 |

### 取得した数字をそのまま出さない

公開データをそのまま並べると、事実だが誤解を招く数字が混ざる。取得時に次を検証し、引っかかったものは画面とレポートに注記として出す。

| 検証 | 実際に引っかかった例 |
|---|---|
| **非継続事業の影響** | ソニーグループの2026年3月期は最終利益が **-3,268億円**。ただしこれは事業分離を含んだ数字で、継続事業ベースでは **+1兆308億円**。稼ぐ力を見る指標としては継続事業ベースが適切なので、そちらを純利益として扱い、乖離を注記する |
| **決算期の飛び** | ニトリホールディングスは決算期変更（2月期→3月期）の移行期がデータに存在せず、`2022-02` の次が `2024-03`。そのまま折れ線にすると連続して見えるため、25ヶ月の飛びを検出して注記する |
| **欠損期** | 売上を取得できなかった期は分析対象から外し、外したことを注記する |

### やらないこと

- **投資判定を出さない** — 独自スコアを根拠にした投資助言になるため。総合スコアは「本ツール独自の参考値」と明示したうえで表示する
- **業界平均と比較しない** — 出典を示せる業界平均値を持っていないため
- **取得できなかった項目を 0 で埋めない** — 「-」と表示する

数値は各社の有価証券報告書と完全に一致することを保証しない。投資判断には使用できない。

## 使い方

```bash
pip install -r requirements.txt
streamlit run main.py
```

ブラウザで `http://localhost:8501` が開く。同梱データが入っているので、初回から何も設定せずに動く。

## データの更新

```bash
python tools/fetch_financials.py
```

`data/financials.json` を作り直す。対象企業を変えるときは `tools/fetch_financials.py` の `TARGETS` を編集する。

## 構成

```
main.py                        画面（企業概要 / 財務分析の2タブ）
components/
  company_overview.py          企業概要の表示
  financial_dashboard.py       財務ダッシュボード（グラフ・指標）
utils/
  data_sources.py              取得層（同梱スナップショット＋ライブ取得）
  financial_analysis.py        財務分析ロジック
  report_generator.py          Markdown レポート生成
tools/
  fetch_financials.py          実データの取得と検証（スナップショット生成）
data/
  financials.json              同梱スナップショット（このファイルが正データ）
```

取得層（`utils/data_sources.py`）と分析・表示は分離してある。データ元を Yahoo! Finance から EDINET などに替えるときは、取得層と `tools/fetch_financials.py` を差し替えれば画面はそのまま動く。
